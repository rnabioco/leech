**`--pod5` can now point at a directory of POD5 files (a MinKNOW run) on the Rust extraction path, not just a single file.** `rust/src/pod5_cache.rs` now resolves reads through `escapepod_signal::cached_dataset` (escapepod-rs#384) instead of `cached_reader`, with no file/directory branch — a single-file input costs nothing extra, since every file a dataset touches is opened through the same per-file reader cache either way. `--backend auto`/`--backend rust` both work on directory input now; `--backend python` already did.
