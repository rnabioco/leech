**`--loss noise_corrected_bce`: a label-noise-aware loss for enrichments with a known, per-group impurity rate.** `losses.NoiseCorrectedBCEWithLogitsLoss` applies a forward correction (Patrini et al. 2017) using a per-sample label-flip probability looked up from each chunk's `source_group` via `--label-noise-rate group=rate[,group=rate,...]` (e.g. `--label-noise-rate gold=0.09,enzymatic=0.17`); groups not named get rate 0 and the loss reduces to plain BCE exactly. Rates are measured upstream (leech does not estimate them) and are recorded verbatim in `config.json`; `predict` is unaffected. Reduces by element count like the other losses, so it decomposes correctly under `--gpus N`.
