**`leech predict --model` on a checkpoint trained with `--dwell-template-table`.**
Single-model predict never loaded `config["dwell_template_table"]`, so a
template checkpoint (`num_features = base + n_aa`) failed shape validation on
the first chunk. `run_inference` now applies the template the same way
`run_bundle_inference` always has, through one shared loader
(`inference/helpers.load_inference_dwell_template`) both call.
