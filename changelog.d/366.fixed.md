**`--dwell-template-table` now divides the actual `dwell` feature row, not whichever row happens to sit at index 0.** Since `--feature-channels` (issue #358) let a corpus/checkpoint's feature rows be a reordered subset, "dwell is row 0" was only a convention nothing checked -- a run with `--feature-channels level_mean,dwell,...` silently divided `level_mean` by the expected dwell instead, at both train and predict time, with every ratio still coming out finite. `LeechDataset` and bundle inference now resolve the row by name (`effective_feature_channels.index("dwell")` / `spec.feature_channels.index("dwell")`), log it once, and raise (`ValueError` / `InferenceConfigError`) when a template is configured but no `dwell` channel is present.
